# Islita v0.10.0

## 中文

- **百分比看哪个窗口由你决定**：设置 → 外观新增「百分比对应」选项，可在自动、5 小时、每周、30 天之间选择。自动保持原来的主窗口（OpenCode Go 为最紧的窗口）；某个服务商没有所选窗口时回退到它的主窗口，数字不会空白。
- **弧线和数字始终一致**：「仅主窗口」模式下圆环也改为绘制所选窗口，不再出现弧线画 5 小时、数字却是每周的情况；「全部窗口」仍为每个窗口单独标注，灵动岛摘要也会跟随该选择。30 天只匹配真正的约 30 天额度，预算窗口不会被误认。
- **设置页重新分组**：17 张卡片按外观与侧栏、位置与行为、提供商与数据、通知与集成、维护与关于五组排列，宽屏两列、窄屏自动一列；提示文字移到控件下方并占满整行，长说明不再挤成窄条。外观卡片新增 General / Percentage / Rings & labels / Surface 小标题，滑块数值直接显示在滑杆旁。
- **插件可以逐个开关**：设置 → 插件为灵动岛的每个内置模块提供独立开关（`disabledPlugins`）。关闭后它会从插件栏和收起态图标中消失，已打开的对应面板关闭，后台角标也停止；本地数据与设置原样保留，之后新增的插件默认开启。
- **灵动岛隐藏时真正贴边**：开启自动隐藏后，隐藏手柄的原生窗口会停靠到显示器工作区顶边（不再停留在 `islandMargin` 下方），悬停展开、停留放大、离开收起的行为不变；关闭自动隐藏或退出灵动岛模式会立即恢复胶囊。
- **桌面宠物更完整**：三套手绘场景（抹茶野餐、深海灯笼、水族箱）可随形象自动匹配，也可手动选择；支持在运行时导入 DyberPet 格式的角色包，带方向行走、随机待机动作和摸头反应，且不捆绑任何 GPL 代码或素材。内置宠物助手直接根据本地额度、费用和宠物数据回答问题，也可选用只连本机回环地址的 Ollama / LM Studio / llama.cpp。
- **DeepSeek 大肥鱼的九段 H3 表演**：待机、行走、奔跑、跳跃、坠落、吃饭、睡觉、开心、难过九段 MiniMax H3 生成动画，在灵动岛面板和桌面窗口同步播放，并跟随饥饿、心情、睡眠、拖拽与服务商状态切换；睡觉的 ZZZ 用 DOM 叠加保持清晰。大肥鱼把 token 和额度叫作「白饭」，低额度时会说「白饭要被吃光了」。
- 兼容性：新增设置项默认 `auto` / 空列表，旧配置文件无需迁移；其余行为与 0.9.0 一致。

## English

- **Choose which window the percentage shows**: Settings → Appearance has a new "Percent refers to" option — automatic, 5-hour, weekly or 30-day. Automatic keeps the previous primary window (the tightest one for OpenCode Go); a provider without the chosen window falls back to its primary, so the number is never blank.
- **Arc and number always agree**: in "primary only" ring mode the ring is now drawn for the selected window too, instead of showing a 5-hour arc next to a weekly number. "All windows" still labels every ring separately, and the island summary follows the same choice. 30-day matches a real ~30-day allowance only, never a budget window.
- **Settings, regrouped**: the seventeen cards now sit under Appearance & sidebar, Placement & behaviour, Providers & data, Notifications & integrations, and Maintenance & about — two columns on wide windows, one when narrow. Hints moved below their controls and use the full row, so long explanations no longer wrap into a thin column. Appearance gained General / Percentage / Rings & labels / Surface subheads, and slider values sit next to the track.
- **Switch plugins on and off**: Settings → Plugins gives every built-in island module its own switch (`disabledPlugins`). A disabled module leaves the rail and the idle capsule, its open panel closes and its background badges stop, while its local data and settings are kept; plugins added by a later release start enabled.
- **The hidden island really docks to the edge**: with auto-hide on, the native window for the thin handle now sits flush with the top of the monitor's work area instead of floating below `islandMargin`. Hover to reveal, rest to expand and leave to hide still work as before; turning auto-hide or island mode off restores the capsule immediately.
- **A more complete desktop pet**: three hand-drawn scenes (Matcha picnic, Deep-sea lantern, Aquarium) follow the selected character or can be chosen by hand, and DyberPet-format character packs can be imported at runtime with directional walks, random idle acts and pat reactions — no GPL code or assets are bundled. The built-in pet assistant answers from local quota, cost and pet data, with an optional loopback-only Ollama / LM Studio / llama.cpp model.
- **Nine H3 performances for the DeepSeek fish**: idle, walk, run, jump, fall, eat, sleep, happy and sad are MiniMax H3 clips that play in both the island panel and the desktop window, switching with hunger, mood, sleep, dragging and provider health; the sleeping ZZZ is a DOM overlay so it stays crisp. The fish calls tokens and quota white rice, including the low-quota line "白饭要被吃光了" (the rice is almost gone).
- Compatibility: new settings default to `auto` / empty lists, so existing settings files need no migration; everything else behaves as in 0.9.0.
