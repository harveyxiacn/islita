# Islita v0.10.2

## 中文

- **灵动岛与插件面板恢复完整尺寸**：0.10.1 仍未解决窗口过小的问题。根因不在面板的尺寸上限，而在原生窗口：侧栏的「自动隐藏」状态机在启动后按 `autoHideDelayMs`（当前配置为 800 ms）把窗口标记为已折叠，而 `sidebar_relayout` 只在窗口「展开」时记录前端测得的尺寸。灵动岛模式不使用这个折叠状态，于是后续测量（完整宽度的胶囊、展开的面板）全被忽略，窗口一直停在初始的 76 px 宽，胶囊和面板都被裁掉。
  现在灵动岛模式下的测量始终生效；同时，灵动岛开启时边缘侧栏的自动隐藏计时器不再运行（灵动岛有自己的、由前端驱动的顶部自动隐藏）。插件面板可以完整展开，胶囊也能完整显示。
- **桌面宠物**：沿用 0.10.1 的修复（H3 首帧占位不再出现重影身体，行走/奔跑按绘制方向镜像）。本版没有改动宠物。
- 兼容性：不改变任何设置项和默认值，0.10.1 的配置文件可直接沿用。

## English

- **The island and its plugin panels get their real size**: 0.10.1 still left the native window too small. The cause was not the panel's size cap but the window itself: after `autoHideDelayMs` (800 ms in this configuration) the edge bar's auto-hide state machine marked the window as collapsed, and `sidebar_relayout` only stored the frontend's measurements while the window was "expanded". Island mode does not use that collapsed state, so every later measurement — the full-width capsule and the opened panel — was ignored and the window stayed at its initial 76 px width, clipping both.
  Island measurements are now always applied, and the edge bar's auto-hide timer no longer runs while the island is on (the island drives its own top-edge auto-hide from the frontend). Plugin panels expand fully and the capsule is no longer cut off.
- **Desktop pet**: keeps the 0.10.1 fixes (no doubled silhouette from the H3 poster, walk/run mirroring on the drawn side). The pet itself is unchanged in this release.
- Compatibility: no settings or defaults changed; a 0.10.1 settings file carries over as is.
