# Islita v0.10.3

## 中文

- **点击互动全面升级**：小八（Hachiware）、麻薯（Mochi）和 DeepSeek 大肥鱼现在共享六种随机反应——蹭蹭、蹦跳、跑圈、吃东西、打盹、闹别扭。每次点击随机抽取一个动作和一句对白（每种声音、每种反应各有 3 句），连续两次点击不会重复同一个动作，对白变体也独立抽取。
- **每种皮肤都有自己的演法**：DeepSeek Q 版播放对应的 H3 动画（happy / jump / run / eat / sleep / sad）；Hachiware 和 DeepSeek 变身形态换成对应的表情卡片，并播放一小段动作；麻薯切换内联表情并使用同一套动作。桌面独立宠物窗口与灵动岛面板共用同一次随机结果，不会两边各演各的。
- 对白全部中英双语；系统开启「减少动态效果」时，保留表情和动画帧切换，只关闭额外的摆动。
- 兼容性：不新增设置项，不改变默认值；0.10.2 的配置文件可直接沿用。

## English

- **Richer click reactions**: Hachiware, Mochi and the DeepSeek fish now share six random performances — nuzzle, bounce, zoomies, munch, doze and sulk. Each click rolls one action and one line (three per reaction for every voice), two clicks in a row never repeat the same action, and the line variant is rolled independently.
- **Every skin performs it its own way**: the DeepSeek chibi plays the matching H3 clip (happy / jump / run / eat / sleep / sad); Hachiware and the transformed DeepSeek form swap to the matching expression card and play a short beat; Mochi changes its inline expression with the same beat. The detached desktop pet and the island panel share the rolled reaction instead of rolling separately.
- All lines are bilingual; with reduced motion on, the expression and clip changes stay and only the extra sway is dropped.
- Compatibility: no new settings and no changed defaults; a 0.10.2 settings file carries over as is.
