# Islita v0.7.0

## 中文

- **你好，Islita**：AI Usage Sidebar 更名为 **Islita**，应用、安装包、二进制（`islita`）、仓库和更新源一并更新；旧仓库地址会自动重定向。它不再只是一个配额侧栏，而是一个可扩展的桌面插件岛。
- **灵动岛（可选开启）**：在屏幕顶部居中显示一颗胶囊。鼠标移入时平滑展开，移出后收回；展开后分为两块——provider 配额环，以及 5×2 的插件网格。展开/收回不再逐帧改变原生窗口大小，修掉了透明窗口重排造成的闪屏。
- **收起时显示什么由你决定**：设置 → 位置里可以勾选最多 6 个 provider 和 6 个插件图标；不选 provider 时仍显示最忙的那个和数量。
- **十个内置插件**：Providers、日历（导入本地 `.ics`，支持简单重复事件）、邮件、微信、已完成任务、便签、最近会话、音乐（本地音频 + LRC 歌词）、专注计时、文件暂存。邮件可以读取本地 `.eml` / Maildir，也可以选择连接 Gmail / Outlook OAuth 或任意 IMAP 账号；只读、只取未读邮件头，正文不读取，凭据存放在系统钥匙串。微信镜像仅 Windows，只读当前可见会话列表。
- **OpenCode Zen / Go（实验性）**：新增 OpenCode 配额，支持 5 小时、每周、30 天窗口；Go 密钥没有 Go 权限时显示 Zen 最紧的月度预算。密钥保存在系统钥匙串，或用 `OPENCODE_API_KEY` 环境变量，绝不写进 `settings.json`。
- **沿用的能力**：四边停靠与自动隐藏、多账号、配额历史、Token 用量与成本估算、会话洞察、提醒与 Webhook、专注模式、命令面板、托盘、`islita --print` 状态栏输出、设置历史/备份/导入导出，全部保留并在新界面上继续工作。
- **从 0.6.0 升级请注意**：应用标识符已改为 `io.github.harveyxiacn.islita`，设置与本地数据库位于新的目录，**不会自动迁移旧版设置和用量历史**。Windows 上 0.7.0 会和旧版并存安装，确认新版无误后再卸载旧版。首次启动按向导重新选择语言、主题和服务商即可。

实验性服务商（GitHub Copilot、OpenRouter、OpenCode）仍未用真实账号验证，默认关闭。所有费用是按 API 价格的估算，不代表订阅账单。

## English

- **Hello, Islita**: AI Usage Sidebar is now **Islita**. The application, installers, binary (`islita`), repository and update feed moved with the name; the old repository URL redirects. It is no longer only a quota sidebar, but a plugin island for the desktop.
- **Dynamic island (opt-in)**: a capsule at the top centre of the screen. It expands smoothly on hover and collapses when the pointer leaves. The expanded form has two blocks: provider quota rings and a 5×2 plugin grid. Expanding and collapsing no longer resize the native window frame by frame, which removes the transparent-window repaint flash.
- **Choose what the collapsed island shows**: Settings → Position lets you pick up to six providers and six plugin icons. With no provider chosen, it still shows the busiest one and a count.
- **Ten built-in plugins**: Providers, Calendar (imports local `.ics`, with simple recurrence), Mail, WeChat, Completed tasks, Sticky note, Recent sessions, Music (local audio + LRC lyrics), Focus timer and File drop. Mail can read a local `.eml` / Maildir folder, or connect Gmail / Outlook over OAuth or any IMAP host with an app password: read-only, unread headers only, message bodies never read, credentials kept in the OS keychain. The WeChat mirror is Windows-only and lists the visible conversations read-only.
- **OpenCode Zen / Go (experimental)**: quota tracking for OpenCode with 5-hour, weekly and 30-day windows; a key without Go access shows the tightest Zen monthly budget instead. The key lives in the OS keychain or in `OPENCODE_API_KEY`, never in `settings.json`.
- **Everything that was already there**: four-edge docking and auto-hide, multiple accounts, quota history, token usage and cost estimates, session insights, alerts and webhooks, focus mode, the command palette, the tray, `islita --print` for status lines, and settings history/backup/import/export all remain.
- **Upgrading from 0.6.0**: the application identifier is now `io.github.harveyxiacn.islita`, so settings and the local database live in new folders and **old settings and usage history are not migrated automatically**. On Windows, 0.7.0 installs alongside the old version; uninstall the old copy once you are happy with the new one. The first-run wizard will ask for language, theme and providers again.

The experimental providers (GitHub Copilot, OpenRouter, OpenCode) have still not been verified against a live account and stay off by default. All costs are API-price estimates, not subscription billing.
