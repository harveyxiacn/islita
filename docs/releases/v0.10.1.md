# Islita v0.10.1

## 中文

- **插件面板恢复完整展开**：修复 0.10.0 中所有插件面板只露出一点内边距、灵动岛窗口不再长高的问题。面板的尺寸上限原先使用 `100vh` / `100vw`，但在灵动岛窗口里它们描述的是胶囊本身（约 120 px 高），`calc(100vh - 13rem)` 会变成负数，面板被压成 0 高度，窗口也就没有理由变大。现在改为按显示器工作区计算：面板随内容展开，超过可用高度时在面板内部滚动，宽度同样以工作区为上限。
- **自动隐藏不再混淆**：开启灵动岛时，「行为 → 自动隐藏为细条」控制的是屏幕边缘侧栏，对灵动岛不起作用。现在它在灵动岛模式下会禁用并说明原因；两者共用的「自动隐藏延迟」在灵动岛自动隐藏开启时仍可调整。灵动岛自己的开关位于「位置 → 灵动岛 → 在屏幕顶部自动隐藏」。
- 兼容性：只修复尺寸计算和设置说明，不改变任何默认值；0.10.0 的配置文件可以直接沿用。

## English

- **Plugin panels expand fully again**: fixes 0.10.0, where every plugin panel showed only its padding and the island window never grew. The panel's size cap used `100vh` / `100vw`, but inside the island window those describe the capsule itself (about 120 px tall), so `calc(100vh - 13rem)` became negative: the panel collapsed to zero height and the window had no reason to grow. The cap now comes from the monitor's work area — panels expand with their content, scroll inside when taller than the available space, and use the same limit for width.
- **No more auto-hide confusion**: while the dynamic island is on, Behaviour → "Auto-hide to a thin handle" controls the screen-edge bar and does nothing to the island. It is now disabled in island mode with an explanation, and the shared "Auto-hide delay" stays editable whenever the island's auto-hide is on. The island's own switch lives under Position → Dynamic island → "Auto-hide at the top edge".
- Compatibility: only size calculations and setting copy changed; no defaults moved, so a 0.10.0 settings file carries over as is.
